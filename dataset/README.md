# Dataset Preparation

Do not fabricate or redistribute copyrighted/private vehicle images.

Suggested classes:
- scratch
- dent
- crack
- bumper_damage
- headlight_damage
- windshield_damage
- paint_damage
- broken_part

Suggested split:
- 70% training
- 20% validation
- 10% testing

For YOLO detection, prepare images and corresponding label files, then create a `data.yaml` describing the paths and class names. Confirm that your dataset license permits academic use and model training.
